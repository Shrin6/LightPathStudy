# absractWity

absractWity is an AI-powered study website built to help students **learn for real** instead of just copying answers.

## Why I built this

I believe many students use AI to cheat on schoolwork because it feels easier in the moment. But for students who actually want to grow their knowledge, that approach hurts long-term learning.

I built absractWity to support students who want to:
- understand topics deeply
- practice active recall
- improve and clean up their notes
- use AI as a learning partner, not a shortcut for cheating

## What this project does

absractWity lets students upload their own materials and turn them into practical study tools, including:
- guided AI tutoring
- quizzes
- flashcards
- worksheet-style practice
- note review and note-fixing support

## Run locally

```sh
npm install
npm run dev
```

## Build
